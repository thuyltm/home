You must be comfortable with the primary GCP data and analytics ecosystem:
- Data Warehousing & Analytics: BigQuery (OLAP, patitioned/clustered tables, BigQuery ML, BI Engine)
- Batch & Stream Processing: Dataflow & Apache Beam (unified batch/streaming, autoscaling, watermarks), Dataproc (maged Spark/Haddop)
- Ingestion & Messaging: Pub/Sub (topics, pull/push subscriptions, streaming ingestion)
- Storage & Databases: Cloud Storage (GCS) for object storage, Cloud Bigtable (NoSQL), Cloud Spanner (globally distributed SQL) and Cloud SQL (Relational)
- Orchestration & ETL: Cloud Composer (managed Apache Airflow), Cloud Fusion, and Datastream (Change Data Capture/CDC)
- Governance & Security: Dataplex, Data Catalog, IAM, encryption-at-rest/in-transit, and data lineage
